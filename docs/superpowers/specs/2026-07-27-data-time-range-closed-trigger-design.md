# Data 时间范围闭合式入口设计

## 背景

Data 时间范围菜单已经改为独立的 Liquid Glass 浮层，并通过稳定挂载的入口与
`materialize` 过渡规避首次展开白闪。本补充设计只调整菜单入口的闭合外观，作为
`2026-07-27-data-time-range-liquid-glass-design.md` 中“时间胶囊”视觉描述的替代；
菜单结构、首次展开修复和所有数据行为保持不变。

用户提供的录屏参考是一种 macOS 闭合选择控件：连续圆角矩形、居中的当前值，以及
右侧固定的上下双箭头。用户明确不需要参考控件左侧的颜色圆点。

## 目标

- 将当前胶囊式入口改为紧凑的闭合式连续圆角矩形。
- 当前时间范围文字在整个控件中几何居中，不因右侧箭头产生视觉偏移。
- 右侧显示固定的上下双箭头，表达这是可展开的选择控件。
- 保留现有 Liquid Glass 质感、尺寸节奏、按压反馈和独立菜单。

## 已确认的视觉设计

1. 入口继续使用现有 `72 × 24pt` 尺寸，不扩大控件或移动刷新按钮。
2. 外形由胶囊改为圆角半径 `8pt` 的连续圆角矩形，形成闭合选择框轮廓。
3. 不显示左侧圆点、颜色标记或其他前导图标。
4. 当前范围文字单独位于控件几何中心。
5. 上下双箭头固定在右侧内边距区域，不参与文字的居中布局；菜单开关时不切换成
   单个向上或向下箭头。
6. macOS 26 原生路径继续使用现有 `.regular.interactive()` Liquid Glass，不能增加
   灰色、白色或 Material 底板。
7. macOS 14/15 与 Reduce Transparency 后备路径只把现有背景和描边裁切形状改为
   相同的连续圆角矩形，不改变辅助功能策略。

## 组件与行为

改动只位于 `DataPrimaryContentView`：

- 增加一个供原生玻璃、fallback 背景、描边和点击区域共同复用的入口形状。
- 入口标签使用中心文字与右侧箭头叠放布局，避免用普通 `HStack` 把“文字 + 箭头”
  整组居中。
- 双箭头是装饰性提示，不单独暴露给辅助功能。
- Button 的现有帮助文本、辅助功能标签、按压样式和点击回调全部保留。

入口仍然只切换 `isTimeRangeDrawerPresented`。菜单打开后入口保持挂载；范围选择、
刷新、点击外部、`Escape`、切页、收起与隐藏时关闭菜单的语义不变。

## 动效与性能

本调整不新增 hover 状态、定时器、异步预热或持续动画。hover 和按下反馈继续由现有
interactive glass 与 `IslandPressButtonStyle` 提供。菜单继续使用已经实现的独立
`materialize` 路径，因此不能恢复入口与菜单之间的 matched-geometry 形变。

## 验证

在 `DynamicIslandCoreChecks` 中补充或更新源码合同：

- Data 时间入口使用连续圆角矩形，不再用胶囊作为玻璃、fallback 或点击形状；
- 入口不包含颜色圆点或前导标记；
- 当前值使用独立居中布局；
- 右侧使用固定上下双箭头，不再依据菜单状态切换单个 chevron；
- 入口仍使用 interactive glass，菜单仍使用独立 `materialize` 过渡；
- 原生玻璃入口没有新增显式背景。

实现后运行：

```bash
swift run DynamicIslandCoreChecks
swift build --product DynamicIsland
./script/build_and_run.sh
```

实际运行时确认：

- 冷启动后首次进入 Data、首次 hover 和首次点击没有新增卡顿；
- 首次展开菜单不出现白色闪烁；
- 闭合入口中文字视觉居中，右侧双箭头清晰但不挤压文字；
- 菜单打开和关闭时入口尺寸、位置与外形保持稳定；
- 静止状态没有新增持续 CPU 占用。

## 范围外

- 修改时间范围选项、统计查询、刷新策略或页面布局。
- 调整菜单尺寸、选项行、材质或过渡。
- 添加颜色标记、前导图标或新的 hover 动画。
- 抽取通用选择控件或重构其他页面。

## 回退

该设计只涉及入口视图与对应源码检查。若闭合形状在目标系统上的玻璃裁切不符合预期，
可单独回退入口形状和标签布局，不回退已经完成的独立菜单与首次白闪修复。
